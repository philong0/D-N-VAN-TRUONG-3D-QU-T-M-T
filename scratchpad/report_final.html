04 — Nguyên nhân gốc

Hai lỗi kiến trúc thật, tìm bằng cách đọc code

#1 — "Half-face" là full-head bị CSS che, không phải geometry thật

ĐÃ SỬA
Canvas3D.tsx:802-815 (trước fix) face-oval-mask.ts

Comment gốc của chính project tự thừa nhận: maskTrianglesByFaceRegion chỉ được dùng để tính camera-framing, còn built.geometry — buffer thật GPU rasterize — vẫn giữ nguyên full head+neck+shoulders. Một CSS maskImage hình elip (đo cứng cho khung 376×700) là thứ DUY NHẤT tạo cảm giác "half-face".

// D27 (nguyên văn, trước khi sửa)
// ...not just re-used for framing math). geometry/atlas contract
// below is untouched, only this metrics calculation uses
// the masked triangle set — the full head+neck+shoulder mesh
// still being RENDERED underneath (unchanged).

Fix: thêm maskAtlasGeometryByFaceRegion() (group-aware, giữ đúng vật liệu atlas theo vùng) + áp trực tiếp lên built.geometry.index/.groups, tính lại normal sau khi cắt. Vignette CSS chỉ còn vai trò làm mềm viền thật, không còn là cơ chế duy nhất tạo half-face.

#2 — Fix #1 tự gây hốc mắt đen do dùng sai vertex-group

ĐÃ SỬA
gnm_texture_atlas.py:674-689 ("D31") loader.ts

Bản fix #1 đầu tiên dùng riêng hockey_mask (row 4/46) để cắt. Nhưng hockey_mask có 0% overlap với các vertex-group eyes/eye_sockets — GNM tách mắt hoàn toàn ra khỏi mask da mặt. ai-engine đã từng gặp đúng lỗi này và tự sửa ở server (comment D31 ghi rõ: "confirmed via a real isolated render" — đã thấy hốc đen thật trước khi sửa) bằng cách hợp nhất 3 group: hockey_mask ∪ eyes ∪ eye_sockets. Phía client chưa từng đồng bộ theo fix này.

hockey_mask row 4   → 0 vertex chung với eyes/eye_sockets
eyes        row 13  → sclera + iris + pupil + interior + exterior
eye_sockets row 16  → da mí mắt quanh hốc mắt

Triangle giữ lại nếu CHỈ dùng hockey_mask :  9,192 / 35,324
Triangle giữ lại khi hợp nhất 3 group     : 13,108 / 35,324  (+3,916 — vùng mắt)

Fix: thêm loadGnmRenderMask() trong loader.ts, mirror đúng công thức _region_mask() phía Python. Cả 2 nhánh cắt geometry trong Canvas3D.tsx chuyển từ faceMask.membership (hockey_mask riêng) sang renderMask.membership (3 group hợp nhất).
